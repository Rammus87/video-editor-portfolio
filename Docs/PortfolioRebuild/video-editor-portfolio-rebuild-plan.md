# 個人剪輯接案網站｜作品主導重構工程計畫

版本：1.0  
日期：2026-07-28  
技術基礎：Vue 3／Vite  
文件狀態：待執行  

---

## 1. 專案目標

將目前偏向「服務與價目表」的個人剪輯接案網站，重構為「作品主導型的個人品牌網站」。

新網站不是先要求訪客閱讀大量服務說明，而是先用代表作品、鮮明美術與互動效果建立印象，再逐步回答：

1. 你的作品是否符合我的需求？
2. 你擅長哪些內容與風格？
3. 你是否可靠、是否有經驗？
4. 價格、時程與合作流程是什麼？
5. 我該如何聯絡你？

預期轉換路徑：

> 視覺吸引 → 播放代表作品 → 瀏覽作品分類 → 理解個人能力 → 查看服務與價格 → 聯絡委託

---

## 2. 參考網站分析結論

參考網站的核心不是「接案平台」，而是「具有作者風格的個人作品檔案庫」。它利用以下方式促使潛在客戶主動發案：

### 2.1 作品是第一層內容

- 首頁使用大型代表視覺建立記憶點。
- 作品圖片所占面積遠高於文字。
- 作品依分類排列，可快速連續瀏覽。
- 點擊作品後可放大或進入詳細內容。
- 作品本身同時負責展示技術、風格與可信度。

### 2.2 個人資訊被包裝成「檔案」

- 自我介紹、經歷、能力與合作經驗不是一般履歷頁，而是帶有明確世界觀的 Profile Archive。
- 大型編號、細線、欄位、標籤與資訊卡，形成具有系統性的編輯排版。
- 數據與成果被放在視覺重點位置，但不使用空泛行銷語言。

### 2.3 互動效果服務於風格

- 滑鼠移動時有局部光暈或邊框回應。
- 導覽與目前分類有明確的高亮狀態。
- 卡片 hover 有細微位移、亮度或邊線變化。
- 經歷內容可展開與收合。
- 作品可使用 Lightbox 放大觀看。
- 頁面切換與內容出現具有節奏，但不依賴大量彈跳動畫。

### 2.4 值得借鑑的原則

- 先展示成果，再說明服務。
- 用一致的視覺系統包裝不同類型內容。
- 讓訪客能用「分類」快速判斷是否適合。
- 讓互動提供探索感，而不是只有裝飾。
- 把聯絡入口放在作品瀏覽之後，承接已建立的興趣。

## 3. 可行性分析

### 3.1 結論

整體可行性：**高，約 8.5／10**。

現有 Vue 3／Vite 架構足以實作參考網站的大部分美術與特效，不需要更換框架。主要限制不是技術，而是：

- 是否有足夠且品質一致的個人作品素材。
- 是否能為作品準備封面、標題、分類與簡短說明。
- 是否控制影片載入量，避免網站過慢。
- 是否避免直接複製對方作品、品牌文字與原始素材。

### 3.2 功能可行性

| 項目 | 可行性 | 建議做法 |
|---|---:|---|
| 深藍、螢光綠、冷藍的視覺系統 | 高 | 使用 CSS Variables 建立設計 Token |
| 大型作品 Hero | 高 | 延用現有 Showreel，重做外框、文字與場景 |
| 作品瀑布流／拼貼網格 | 高 | CSS Grid，依作品比例配置版位 |
| 作品分類與目前分類高亮 | 高 | Vue 狀態或 Vue Router |
| 作品 Lightbox | 高 | Teleport、焦點鎖定、Esc 關閉 |
| 滑鼠光暈與邊線發光 | 高 | CSS 變數＋requestAnimationFrame |
| 輕量卡片傾斜 | 高 | 最大 1.5–2 度，僅桌面精準指標裝置 |
| 經歷 Accordion | 高 | Vue Transition＋CSS Grid Rows |
| 頁面／區塊轉場 | 高 | CSS Transition 為主，JS 僅處理進度 |
| 多影片同時預覽 | 中 | 不建議自動播放；封面優先、點擊播放 |
| 完全一比一複製 | 不建議 | 改做設計語言與互動邏輯的原創轉譯 |

### 3.3 內容可行性

若只有一支 Showreel，可以先完成首頁，但無法形成參考網站那種「作品檔案庫」的說服力。

建議素材門檻：

- 最低可發布：3 個作品。
- 建議第一版：6–9 個作品。
- 理想狀態：每個類別至少 3 個作品。

三個既有服務類別可直接成為作品分類：

- 短片
- 長片
- 航拍素材

### 3.4 法律與品牌邊界

可以借鑑：

- 色彩關係
- 編輯式排版
- 導覽邏輯
- 作品網格
- 光暈、邊線、Lightbox、Accordion 等一般互動模式

不可直接複製：

- 對方作品與圖片
- 品牌名稱、Logo、個人資料與文案
- 原始程式碼
- 具有高度識別性的圖形素材
- 完全相同的頁面配置、動畫時間與細節組合

工程目標應是「看到同一類型的藝術指導與探索感」，而不是逐像素仿製。

## 4. 建議網站架構

為了接近參考網站的瀏覽方式，建議由目前單頁式網站升級為多視圖 SPA。仍使用 Vue，不需要改成其他框架。

### 4.1 導覽結構

```text
首頁／精選作品
├── 作品目錄
│   ├── 全部
│   ├── 短片
│   ├── 長片
│   └── 航拍素材
├── 個人檔案
├── 服務與價格
└── 聯絡方式
```

### 4.2 建議路由

```text
/                 首頁：Showreel、精選作品、簡短自介、聯絡 CTA
/works            作品目錄與分類
/works/:slug      單一作品詳情，或使用可分享網址的 Lightbox
/profile          個人介紹、經歷、能力與合作項目
/services         既有服務、價格、合作流程、方案建議、聯絡方式
```

若第一階段不希望加入 Vue Router，可先在單頁中完成對應區塊；但完整版本仍建議使用路由，讓作品能被單獨分享。

### 4.3 內容優先順序

首頁：

1. 個人識別與一句明確定位
2. Showreel 或代表作
3. 精選作品
4. 能處理的三種內容
5. 個人簡介與可信度
6. 服務入口
7. 聯絡方式

服務頁：

1. 短片／長片／航拍素材
2. 價格
3. 包含內容
4. 合作流程
5. 長期合作（僅短片）
6. 方案建議工具
7. 聯絡方式

## 5. 視覺方向

### 5.1 整體定位

關鍵詞：

> 個人作者感、作品檔案、數位影像、冷色深夜、少量螢光、精準、可探索

避免：

- 每個區塊都是圓角卡片
- 大量漸層球與裝飾性光斑
- 所有元素同時進場
- 過度對稱、過度置中
- 無內容意義的英文標籤
- 大面積純黑造成過度嚴肅
- 套版式 AI 生成文案

### 5.2 建議色彩 Token

```css
:root {
  --color-bg: #080b1f;
  --color-surface: #0d1430;
  --color-surface-soft: #131d3c;
  --color-text: #f5f7ff;
  --color-text-muted: #9eabc5;
  --color-line: rgba(125, 174, 226, 0.28);
  --color-blue: #58b8ff;
  --color-accent: #dfff00;
  --color-accent-ink: #101506;
}
```

現有天空 Hero 可保留為個人識別素材，但首頁下半部與作品目錄改為深海軍藍的作品檔案介面。這樣既延續現在的 Showreel，也能接近參考網站的數位作品庫氛圍。

### 5.3 排版原則

- 主標題使用大型無襯線粗體。
- 作品名稱比說明文字更重要。
- 以編號、細線、欄位與留白建立結構。
- 中文為主要語言；英文只保留類別、軟體、平台或作品原名。
- 每段文字控制在 2–4 行。
- 作品卡不承載價格與流程，避免作品與報價資訊互相搶戲。

## 6. 動效規格

### 6.1 游標光暈

- 僅在 `(hover: hover) and (pointer: fine)` 啟用。
- 使用 CSS 自訂屬性更新游標座標。
- 更新包在 `requestAnimationFrame`，避免每次 pointermove 都直接觸發重繪。
- 光暈透明度低於 0.18，不遮蓋作品。
- 手機與 `prefers-reduced-motion` 關閉。

### 6.2 作品卡 Hover

- 邊線或局部背景亮度改變。
- 圖片最大放大 1.02。
- 卡片傾斜不超過 2 度。
- 進出時間 160–220ms。
- 不使用大幅上浮、彈跳或反覆閃動。

### 6.3 Scroll Reveal

- 只用於首屏、精選作品第一批內容與大區段標題。
- 同一畫面最多 3 組依序出現。
- 內容一旦顯示便保持穩定，不因捲動反覆播放。
- 不用會改變文件高度的動畫，避免下方內容跳動。

### 6.4 Lightbox

- 點擊作品後放大顯示圖片或播放影片。
- 支援 Esc 關閉、背景點擊關閉、上一個／下一個。
- 開啟時鎖定頁面捲動。
- 關閉後焦點回到原本作品卡。
- 手機以滿版觀看，桌面保留安全邊距。

### 6.5 Accordion

- 用於個人經歷或作品補充資訊。
- 同一時間預設只展開一項。
- 動畫 220–300ms。
- 不改動主作品網格的位置。

### 6.6 導覽與頁面切換

- 目前頁面或分類使用螢光綠標記。
- Scroll Spy 只更新狀態，不自動搶走焦點。
- 頁面切換使用輕量透明度與 8–12px 位移。
- 所有動效必須提供 reduced-motion 的直接顯示版本。

## 8. 作品素材規格

每個作品至少需要：

| 素材 | 建議規格 |
|---|---|
| 原始影片 | MP4／H.264，另可補 WebM |
| 作品封面 | WebP 或 AVIF，長邊 1600–2000px |
| 直式裁切 | 9:16，適用短片作品卡 |
| 橫式裁切 | 16:9，適用長片與 Hero |
| 作品名稱 | 10–24 個中文字以內 |
| 摘要 | 25–60 字 |
| 負責內容 | 3–6 個標籤 |
| 平台與片長 | 真實資訊 |
| 客戶資訊 | 取得公開許可才顯示 |

載入原則：

- 首頁只預載 Showreel 的 metadata 或 poster。
- 作品列表使用封面，不同時自動播放多支影片。
- 影片在使用者點擊後才載入或播放。
- 圖片提供 `srcset`、明確寬高與 lazy loading。

## 9. 效能與無障礙標準

### 9.1 效能目標

- LCP：小於 2.5 秒。
- INP：小於 200ms。
- CLS：小於 0.1。
- 初始頁不載入全部作品影片。
- 游標動畫不讀寫混用造成 layout thrashing。
- 所有動畫優先使用 `transform` 與 `opacity`。

### 9.2 無障礙

- 所有功能可用鍵盤操作。
- Focus 樣式不可移除。
- Lightbox 有正確 dialog 語意。
- 圖片有符合內容的 alt。
- 影片有標題，必要時提供字幕或文字摘要。
- 按鈕觸控範圍至少 44×44px。
- 文字與背景符合 WCAG AA 對比。
- 支援 `prefers-reduced-motion`。

## 10. 主要風險與處理方式

| 風險 | 影響 | 處理方式 |
|---|---|---|
| 個人作品數量不足 | 網站像概念稿，不像作品庫 | 先用 3 個真實作品完成 MVP，不使用假案例 |
| 過度仿製參考網站 | 缺乏個人識別，也有侵權疑慮 | 借鑑系統，不複製素材與逐像素配置 |
| 動畫太多 | 再次產生 AI 感與操作疲勞 | 動效分三級，只有 Hero 與作品互動屬強動效 |
| 多影片拖慢首頁 | LCP 與手機體驗下降 | poster 優先，點擊後才載入影片 |
| 手機沒有 hover | 互動資訊消失 | 手機預設顯示必要標題與類別 |
| 重構破壞既有報價邏輯 | 商業資訊錯誤 | 服務資料只讀保留，分階段回歸測試 |
| 專案沒有 Git | 難以安全回復 | 開始修改前先建立可回復基準或完整副本 |
| 一次改動範圍過大 | 難以判斷哪一步變差 | 每次只完成一個階段並截圖驗收 |

## 11. 分階段工程步驟

### Phase 0｜現況盤點與可回復基準

目標：

- 確認實際專案路徑、依賴、路由、資產與目前功能。
- 保存 1440、768、390px 的修改前畫面。
- 確認是否為 Git repository。
- 在任何視覺修改前建立可回復基準。

驗收：

- 不修改現有 UI、資料與功能。
- 有完整檔案盤點與風險列表。
- 有修改前截圖。
- 有明確回復方式。

### Phase 1｜設計系統與靜態原型

目標：

- 建立深海軍藍作品檔案主題。
- 定義色彩、字級、欄寬、間距、邊線與動效 Token。
- 先以靜態資料完成首頁與作品目錄骨架。

驗收：

- 不接入複雜動效。
- 1440、768、390px 皆無水平捲動。
- 首頁先看到作品，不先看到價目表。
- 既有服務頁仍可正常使用。

### Phase 2｜作品資料與素材管線

目標：

- 新增 `portfolio.js`。
- 建立作品資料夾與命名規則。
- 接入 3 個真實作品作为 MVP。
- 產生封面與響應式圖片。

驗收：

- 缺少影片時仍能用 poster 正常呈現。
- 每個作品都可透過 slug 唯一識別。
- 不使用假客戶、假成效或假作品。

### Phase 3｜首頁作品敘事

目標：

- 重做 Hero，使個人定位、Showreel 與代表作品成為主體。
- 新增精選作品網格。
- 新增簡短個人介紹與作品目錄入口。

驗收：

- Hero 只有一個主要 CTA。
- 首屏載入不下載所有作品影片。
- 精選作品點擊行為明確。

### Phase 4｜作品目錄與分類

目標：

- 完成全部／短片／長片／航拍素材分類。
- 使用不規則但可控的作品網格。
- 加入目前分類高亮與網址狀態。

驗收：

- 分類切換不造成大幅版面跳動。
- 鍵盤可以操作分類。
- 手機不用 hover 也看得到作品名稱與類別。

### Phase 5｜作品詳情與 Lightbox

目標：

- 點擊作品可放大播放。
- 支援上一個／下一個、Esc、焦點回復。
- 每個作品有可分享的詳情網址。

驗收：

- 背景不會在 Lightbox 開啟時捲動。
- 影片關閉後停止播放。
- 瀏覽器返回鍵行為正確。

### Phase 6｜個人檔案

目標：

- 建立個人介紹、能力、工具、經歷與可公開成果。
- 使用 Archive／Profile 的編輯式排版。
- 經歷可展開，但不影響作品瀏覽主線。

驗收：

- 不使用虛構數字與空泛能力條。
- 自介能在 20 秒內閱讀完成。
- 經歷 Accordion 無版面閃跳。

### Phase 7｜服務與價格整合

目標：

- 將既有服務、價格、流程、長期合作與推薦工具移至作品敘事之後。
- 不變更商業資料與推薦邏輯。
- 讓服務頁與作品頁使用同一套視覺語言。

驗收：

- 所有價格與交付時間與目前版本一致。
- 「修改至滿意」文案保持正確。
- 長片不顯示長期合作。
- 航拍價格仍為車馬費＋每 5 分鐘 NT$1,000。

### Phase 8｜互動與動效

目標：

- 加入游標光暈、邊線回應、卡片細微傾斜、Scroll Spy 與頁面轉場。
- 動效採漸進增強，不影響基本功能。

驗收：

- reduced-motion 下直接顯示內容。
